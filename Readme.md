# 미국 ETF 큐레이션 서비스 기획

### 1. 데이터 전처리

- 활용 데이터: 미국 주식, ETF 관련 데이터 및 NH투자증권 고객의 투자 내역 데이터
- 분석 대상 선정 및 결측치 제거
    - 2024.05.28~2025.08.26 내의 정보가 존재하는 종목으로 선정
- EDA
    - 상관관계 분석
- 파생변수 생성 및 변수 선택

### 2. 군집 분석

- DTW 클러스터링을 활용한 미국 투자 종목 분석
    - 투자는 시간에 따른 움직임이 중요한 요소이기 때문에 시계열 특성을 고려한 유사성 계산 방법인 DTW 기법 선택
    - 군집화를 위한 변수 전처리: 정규화 및 로그 변환 진행

### 3. 고객 투자 성향 분석

- 고객의 ‘종목 구매 비율’을 군집 별로 비교하여 고객군의 투자 성향 분석

### 4. 결론

- 수익성, 안정성, 거래량에 따라 고객군이 선호하는 투자 종목의 차이가 존재함을 확인

### 5. 미국 ETF 큐레이션 서비스 구현

- 미국 ETF 큐레이션 서비스 흐름 설계
    - 고객 정보 입력 → 고객 투자 성향 계산/분석 → 추천 ETF 종목 선정 → 추천 ETF 종목 제시 → 궁금한 ETF 종목 검색 → ETF 종목 정보 제시 → 반복 혹은 종료
- 환경 설정 및 데이터 로드
    - Microsoft Azure의 OpenAI와 Blob Storage를 활용하기 위해 환경 변수 로드, API 설정, 데이터 로드
- 추천 ETF 종목 선정
    - 군집 분석 결과를 기반으로 군집별 수익성, 안정성, 거래량 선호도 점수를 계산하여 사용자 투자 성향을 정량화
    - 사용자와 유사한 고객군이 선호하는 종목 추천
- OpenAI를 활용한 ETF 특징 추출
    - GPT 모델을 기반으로 프롬프트를 설계하고 조정하여 사용자에게 ETF의 특징을 반환
- UI 설계
    - Gradio 패키지를 활용해 큐레이션 서비스를 UI로 구현
